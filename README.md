# Lean matrix families

The five matrix families are C, X₄, X₅, Y, and Z. Their shared definitions
are in [Families.lean](LeanProject/Families.lean).

- [main](https://github.com/ckhj123/lean_project/tree/main) contains the
  skew symmetry and zero row sum results for all five families.
- [ai](https://github.com/ckhj123/lean_project/tree/ai) also contains the
  cyclic adjacent smoothability proofs. See the
  [proof review checklist](https://github.com/ckhj123/lean_project/blob/ai/docs/PROOF_REVIEW.md)
  for Lean verification, provenance, and mathematical review status.
